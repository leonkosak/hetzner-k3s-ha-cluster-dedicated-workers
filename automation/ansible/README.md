# Ansible

## Inventory

The inventory is auto-generated by `hcloud-create-servers.sh` at `../scripts/hcloud_servers_inventory.yml`.
No manual inventory file is needed — run the server creation script first, then use the `ansible.cfg`
in this directory which points to it automatically.

```bash
cd ../scripts
./hcloud-create-servers.sh
```

## Playbooks

- `playbooks/bootstrap-os.yml`
- `playbooks/install-k3s-servers.yml`
- `playbooks/install-k3s-agents.yml`
- `playbooks/install-nvidia-runtime.yml`
- `playbooks/upgrade-os.yml`
- `playbooks/upgrade-k3s.yml`

## Typical run order

Run from this directory (inventory is picked up from `ansible.cfg`):

```bash
ansible-playbook playbooks/bootstrap-os.yml
ansible-playbook playbooks/install-k3s-servers.yml
ansible-playbook playbooks/install-k3s-agents.yml
```
